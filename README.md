# BANEXUS

Venture builder focused on turning promising projects into independent businesses.

## Overview

BANEXUS identifies promising projects, takes the development and market risk, builds products, takes them to market, and scales ventures that show real potential.

The BANEXUS venture-building process is:

```text
Discover → Validate → Build → Launch → Scale → Spin Out
```

## Website

The BANEXUS website presents:

* The BANEXUS venture-building model
* Current and upcoming ventures
* BANEXUS principles
* The venture development process
* A project submission workflow

## Ventures

### VECAI

Construction technology platform focused on construction planning, project management, materials, and decision support.

Status: Building

### Chemichemi

Water intelligence platform focused on water-quality information for communities, farmers, and decision-makers.

Status: Concept

### Digital SACCO

Digital financial infrastructure focused on informal-sector communities.

## Getting Started

### Prerequisites

Install the tools required by the project's current technology stack.

### Installation

Clone the repository:

```bash
git clone <repository-url>
cd banexus
```

Install dependencies:

```bash
npm install
```

### Development

Start the development server:

```bash
npm run dev
```

Open the local development URL provided by the framework.

### Production Build

Create a production build:

```bash
npm run build
```

Run the production application:

```bash
npm start
```

Use the commands defined in `package.json` if they differ from the commands above.

## Development Guidelines

Before committing changes:

1. Test new functionality.
2. Check responsive layouts.
3. Check navigation.
4. Check forms and interactions.
5. Check for console errors.
6. Review the Git diff.
7. Keep commits focused and descriptive.

Use conventional commit messages where appropriate:

```text
feat: add venture portfolio
fix: improve mobile navigation
refactor: simplify venture components
docs: update readme
```
